# 나의 카드 덱

카드 앞면·뒷면 사진을 세트(확장팩)별로, 넣은 순서대로 보여 주는 정적 페이지.
GitHub public 저장소 + GitHub Pages로 배포한다(https://spica07.github.io/card-collection/). 로컬에서는 `index.html`을 더블클릭해도 열린다(서버 필요 없음). 카드를 넣고 커밋·푸시하면 1~2분 뒤 사이트에 반영된다.

## 카드 넣기

```bash
py tools/add.py "30주년 확장팩" "뮤츠ex SAR 128" --front 앞.jpg --back 뒤.jpg
```

- 사진에서 카드만 찾아 반듯하게 펴서 `cards/<NN-세트>/<번호>-<이름>-front|back.jpg`로 저장하고 `cards.js`를 다시 만든다.
  카드 찾기는 `C:/blog_writing/.claude/skills/card-centering`의 검출 코드를 쓴다 (opencv-python, numpy).
- **센터링도 같이 잰다.** card-centering 스킬과 같은 측정으로 앞뒷면 좌우·상하 비율과 PSA·CGC·TAG·BGS 센터링 상한을 내고,
  `cards/<세트>/<번호>-centering.json`에 저장한다(한 면만 다시 넣으면 그 면만 바꾸고 등급은 다시 계산).
  확인 이미지(검출선)는 `centering/<세트>/<번호>-front|back.jpg`(웹에 올리므로 PNG 대신 JPEG 품질 85) — 터미널에 신뢰도가 high가 아니라고 나오면 꼭 열어 본다.
  안쪽 경계가 틀리면 `--front-inner=-,-,-,1700`처럼 펴진 이미지 좌표(1260x1760, -는 자동)로 지정한다. 재지 않으려면 `--no-centering`.
- 세트가 처음이면 다음 순번으로 폴더를 만든다 (예: `02-블랙볼트`). 세트 순서는 폴더 앞 번호.
- 번호는 그 세트의 마지막 번호 + 1. `--no 3`처럼 주면 그 번호로 넣고, 같은 번호면 덮어쓴다.
- **넣은 뒤 잘린 사진을 꼭 눈으로 확인한다.** 은색 테두리 카드를 회색 천에 찍으면 외곽을 엉뚱하게 잡고도
  멈추지 않을 수 있다 (뮤츠ex SAR에서 실제로 발생). 그때는 원본 사진 픽셀의 대략 꼭짓점을 준다:
  `--no 1 --front-corners "295,493;2591,467;2628,3797;237,3782"` (왼쪽 위부터 시계 방향).
- `--raw`: 자르지 않고 원본 그대로 넣기.

card-centering 스킬의 회사별 기준표(`grading_standards.json`)가 바뀌면 `py tools/regrade.py`로 저장된 비율에서 예상 등급만 다시 계산한다(사진을 다시 재지 않음). BRG는 공식 기준표를 찾지 못해 2차 출처의 10등급 값(60:40) 하나만 쓴다.

손으로 `cards/` 폴더에 파일을 넣거나 지웠다면 `py tools/build.py`로 덱을 다시 만든다.
`build.py`는 덱 썸네일(`thumbs/<세트>/`, 폭 360px)도 만든다. 원본보다 새것이면 건너뛰고, 쓰지 않는 썸네일은 지운다. 썸네일도 커밋해야 사이트에 반영된다.
파일 이름 규칙: `<번호>-<이름>-front.jpg` / `-back.jpg` (`앞`/`뒤`, 구분 기호 `_`·공백도 됨).

## 화면

- 세트 탭(전체/세트별), 오른쪽 위 앞면·뒷면 전환(덱 전체를 뒷면으로 보기)
- 덱 썸네일 오른쪽 위에 센터링 기준 PSA 예상 등급 배지("PSA 10 예상"). 세트 탭으로 거르면 크게 보기의 이전/다음도 그 세트 안에서만 움직인다
- 카드를 누르면 크게 보기: 오른쪽(휴대폰은 아래)에 센터링 표, PSA와 BRG 예상 등급(경계 표시, 등급을 결정한 면·축과 경계 근거를 화면에 바로 표시), 확인 이미지 링크. 카드를 누르거나 `뒤집기`로 앞뒤 전환, ←/→ 이전·다음, Space·F 뒤집기(카드에 포커스가 있으면 Enter도), Esc 닫기. 크게 보기가 열린 동안 뒤쪽 화면은 `inert`라 Tab이 창 밖으로 나가지 않는다, 휴대폰은 좌우로 밀기
