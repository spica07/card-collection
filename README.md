# 나의 카드 덱

카드 앞면·뒷면 사진을 덱(내 덱, 친구 덱)과 세트(확장팩)별로, 넣은 순서대로 보여 주는 정적 페이지.
GitHub public 저장소 + GitHub Pages로 배포한다(https://spica07.github.io/card-collection/). 로컬에서는 `index.html`을 더블클릭해도 열린다(서버 필요 없음). 카드를 넣고 커밋·푸시하면 1~2분 뒤 사이트에 반영된다.

## 카드 넣기

```bash
py tools/add.py "30주년 확장팩" "뮤츠ex SAR 128" --front 앞.jpg --back 뒤.jpg
```

- **덱:** `--deck "친구 덱"`처럼 고른다(기본 `내 덱`). 폴더는 `cards/<NN-덱>/<NN-세트>/`, 확인 이미지는 `centering/<NN-덱>/<NN-세트>/`, 썸네일은 `thumbs/<NN-덱>/<NN-세트>/`. 새 덱 이름을 주면 다음 순번으로 폴더를 만든다. 빈 덱은 폴더에 `.gitkeep`을 두어 남긴다.
- **카드 종류:** 이름에 `ex`가 있으면 포켓몬 ex, 없으면 포켓몬. 트레이너스·에너지는 이름으로 알 수 없어 `--kind trainer`(또는 `energy`)로 넣는다 → `<번호>-info.json`. 이름에 `복각`이 있으면 복각으로 친다.
- **카드 구분(레어도):** 카드 이름에 `SAR`, `SR`, `AR` 같은 표기를 넣으면 덱 화면의 `카드 구분` 필터에 잡힌다(예: `뮤츠ex SAR 128`). 표기가 없으면 `표기 없음`.

- 사진에서 카드만 찾아 반듯하게 펴서 `cards/<NN-세트>/<번호>-<이름>-front|back.jpg`로 저장하고 `cards.js`를 다시 만든다.
  카드 찾기는 `C:/blog_writing/.claude/skills/card-centering`의 검출 코드를 쓴다 (opencv-python, numpy).
- **센터링도 같이 잰다.** card-centering 스킬과 같은 측정으로 앞뒷면 좌우·상하 비율과 PSA·CGC·TAG·BGS 센터링 상한을 내고,
  `cards/<세트>/<번호>-centering.json`에 저장한다(한 면만 다시 넣으면 그 면만 바꾸고 등급은 다시 계산).
  확인 이미지(검출선)는 `centering/<세트>/<번호>-front|back.jpg`(웹에 올리므로 PNG 대신 JPEG 품질 85) — 터미널에 신뢰도가 high가 아니라고 나오면 꼭 열어 본다.
  안쪽 경계가 틀리면 `--front-inner=-,-,-,1700`처럼 펴진 이미지 좌표(1260x1760, -는 자동)로 지정한다. 재지 않으려면 `--no-centering`.
- **상세 감정(모서리, 옆면)도 같이 한다.** card-centering 스킬의 `condition.py`로 흠 의심 자리(빨간 번호)와 조명 반사일 수 있는 자리(주황 점선)를 찾아
  `cards/<세트>/<번호>-condition.json`에 카드 기준 %좌표로 저장한다. 앞면은 모서리 모양만, 뒷면은 모서리와 옆면 흰 점까지 본다.
  원본 사진(4000x3000 정도)이어야 의미가 있다. 자동 외곽이 틀린 사진은 `--back-corners`처럼 꼭짓점을 주면 상세 감정에도 그대로 쓴다. 하지 않으려면 `--no-condition`.
- 세트가 처음이면 다음 순번으로 폴더를 만든다 (예: `02-블랙볼트`). 세트 순서는 폴더 앞 번호.
- 번호는 그 세트의 마지막 번호 + 1. `--no 3`처럼 주면 그 번호로 넣고, 같은 번호면 덮어쓴다.
- **넣은 뒤 잘린 사진을 꼭 눈으로 확인한다.** 은색 테두리 카드를 회색 천에 찍으면 외곽을 엉뚱하게 잡고도
  멈추지 않을 수 있다 (뮤츠ex SAR에서 실제로 발생). 그때는 원본 사진 픽셀의 대략 꼭짓점을 준다:
  `--no 1 --front-corners "295,493;2591,467;2628,3797;237,3782"` (왼쪽 위부터 시계 방향).
- `--raw`: 자르지 않고 원본 그대로 넣기.

card-centering 스킬의 회사별 기준표(`grading_standards.json`)가 바뀌면 `py tools/regrade.py`로 저장된 비율에서 예상 등급만 다시 계산한다(사진을 다시 재지 않음). BRG는 공식 기준표를 찾지 못해 2차 출처의 10등급 값(60:40) 하나만 쓴다.

손으로 `cards/` 폴더에 파일을 넣거나 지웠다면 `py tools/build.py`로 덱을 다시 만든다.
`build.py`는 덱 썸네일(`thumbs/<세트>/`, 폭 360px)도 만든다. 원본보다 새것이면 건너뛰고, 쓰지 않는 썸네일은 지운다. 썸네일도 커밋해야 사이트에 반영된다.
파일 이름 규칙: `<번호>-<이름>-front.jpg` / `-back.jpg` (`앞`/`뒤`, 구분 기호 `_`·공백도 됨).

## 화면

- 맨 위 덱 고르기(내 덱/친구 덱, 고른 덱은 이 브라우저에 기억). **친구 덱은 카드마다 번호가 따로 있고, 번호를 넣은 카드만 보인다** — 친구 덱을 누르면 번호 입력창이 뜨고, 맞는 번호를 넣을 때마다 그 카드가 덱에 하나씩 나타난다. 번호는 `py tools/pin.py`가 만든다(번호 없는 카드에만 새로 만들어 터미널에 한 번만 보여 줌, 없어진 카드 번호는 지움, `--reset "친구 덱/세트/번호"`로 다시 만들기, `--list`로 목록). `locks.js`에는 번호 대신 `sha256("card-collection:" + 번호)` → `덱/세트/카드번호`만 둔다. **친구 덱에 카드를 넣은 뒤에는 꼭 `py tools/pin.py`를 돌리고** `sw.js` CACHE를 올려 커밋·푸시한다(번호 없는 카드는 화면에 안 나온다). 연 카드는 그 탭(sessionStorage)에만 남아 탭을 닫으면 다시 잠긴다. 정적 public 사이트라 화면만 가리는 잠금이다 — 저장소나 `cards.js`, 사진 주소로는 누구나 볼 수 있고, 6자리 번호는 해시로도 금방 풀린다, 세트 탭(전체/세트별), 기본 필터(늘 보임): 예상 등급(PSA), 레어도. `상세 필터` 버튼(처음엔 접힘): 센터링(앞면에서 가장 치우친 축 51 이하/51~53/53~55/55~60/60 넘음), 레어도 계열(일러스트 AR·SAR·CHR·CSR / 풀아트·골드 SR·UR·MUR… / 일반 RR 이하 / 표기 없음), 카드 종류(포켓몬 ex/포켓몬/트레이너스/에너지), 복각(복각만/복각 아님). 칩 옆 숫자는 그 칩을 골랐을 때 보일 장수이고, 0장인 칩은 숨긴다. 필터는 세트 탭과 함께 걸리고 크게 보기의 이전/다음도 걸린 카드 안에서만 움직인다.
- 세트 탭(전체/세트별), 오른쪽 위 앞면·뒷면 전환(덱 전체를 뒷면으로 보기)
- 덱 썸네일 오른쪽 위에 센터링 기준 PSA 예상 등급 배지("PSA 10 예상"). 세트 탭으로 거르면 크게 보기의 이전/다음도 그 세트 안에서만 움직인다
- 카드를 누르면 크게 보기: 오른쪽(휴대폰은 아래)에 센터링 표, PSA와 BRG 예상 등급(경계 표시, 등급을 결정한 면·축과 경계 근거를 화면에 바로 표시), 확인 이미지 링크, 상세 감정 요약과 `상세 감정 보기` 버튼.
- 상세 감정 화면(크게 보기와 따로): 앞면과 뒷면을 나란히(휴대폰은 위아래로) 크게 놓고 흠 의심은 빨간 번호, 반사 의심은 주황 점선 R번호로 카드 위에 겹쳐 그린다. 목록을 누르면 그 표시가 깜빡이고, `레드마크 표시`로 켜고 끈다. `카드로` 버튼이나 Esc로 크게 보기로 돌아간다. 카드를 누르거나 `뒤집기`로 앞뒤 전환, ←/→ 이전·다음, Space·F 뒤집기(카드에 포커스가 있으면 Enter도), Esc 닫기. 크게 보기가 열린 동안 뒤쪽 화면은 `inert`라 Tab이 창 밖으로 나가지 않는다, 휴대폰은 좌우로 밀기

## 앱 설치(PWA)

`manifest.webmanifest` + `sw.js` + `icons/`로 홈 화면에 앱으로 설치할 수 있습니다(안드로이드 크롬 "앱 설치", 아이폰 사파리 "홈 화면에 추가").
서비스워커는 네트워크 우선이라 카드를 추가하고 푸시하면 바로 반영되고, 인터넷이 없을 때만 한 번 본 화면·사진을 캐시에서 엽니다. 캐시 구조를 바꿀 때만 `sw.js`의 `CACHE` 버전을 올립니다.

## 박스 정가 페이지

`prices.html` — 포켓몬 카드 한글판 박스별 공식 정가(구성, 정가, 팩당 가격). 덱 화면 제목 아래 `박스 정가 보기` 링크로 들어간다.
데이터는 `prices.html` 안의 `BOXES` 배열(위가 최신 출시)에 직접 적는다. 새 박스가 나오면 맨 위에 한 줄 넣고 `sw.js` CACHE를 올린다.
